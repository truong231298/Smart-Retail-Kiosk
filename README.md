# RoShopSmart AI Retail Kiosk

Nền tảng kiosk bán lẻ tự phục vụ tích hợp AI, computer vision và IoT.

## Cấu trúc

- `docs/`: tài liệu vision, yêu cầu, kiến trúc, AI, bảo mật và roadmap.
- `.github/workflows/`: các quy trình CI/CD.
- `docs/diagrams/`: sơ đồ kiến trúc và luồng nghiệp vụ.

## Bắt đầu

1. Sao chép `.env.example` thành `.env` và cập nhật các giá trị cần thiết.
2. Đọc [01-project-vision.md](docs/01-project-vision.md) và [03-system-architecture.md](docs/03-system-architecture.md).
3. Bổ sung implementation theo roadmap trong [12-roadmap.md](docs/12-roadmap.md).
